# 设计关键词提炼与校准

## 两组关键词

- **参考搜索词**：组合业务场景、页面类型与关键模块，定位具体案例。例如“趣味测试＋结果海报＋分享页”；不要一次堆入所有材质与配色，以免只搜到相似装饰。
- **设计执行词**：规定主题、构图、素材、配色、信息层级和行动方式。例如“身份卡主题、结果优先、立体纸张、深蓝主色、蓝红点缀、金色主按钮”。每个词应有对应的可见设计决策。

## 关键词卡

按业务填写以下六项，篇幅随复杂度调整，不凑词数：

1. 页面目标：用户看完应理解什么、采取什么行动。
2. 设计倾向：偏运营活动页或偏数据展示；与平台、尺寸及既有品牌约束一致。
3. 核心概念：能连接业务内容的主题，运营页尤其需要明确，不凭空扩展玩法。
4. 视觉表现：主视觉题材及材质、配色主次、构图焦点、文字与数字层级。
5. 行动引导：核心按钮、互动入口与分享理由；没有分享需求则不强加。
6. 排除项：明确本项目避免的布局、装饰或素材处理。

附上两组关键词，并区分：用户明确要求／来自参考观察／设计提案。选出主导方向，将辅助表现置后，避免把所有形容词设为同等优先。

## 校准方法

- **业务关联**：主题素材必须解释或强化页面目标，不能用泛化科技光球等无关物替代创意。
- **可执行性**：把“高级”展开成具体材质、光线、留白或排版关系；把“海报感”展开成主视觉、标题和结果的观看顺序。
- **冲突检查**：如极简留白与高密度同时出现，说明各自作用区域或确定优先级；无法协调且影响方向时随风格选择澄清。
- **证据对应**：三站图片只支持实际看到的视觉结论。校准卡注明哪些词有V级参考支持，哪些仍是C级概念；不要把主观提案说成已验证效果。
- **研究反馈**：依据实际案例保留、细化或替换初稿词，简述有意义的调整。无有效图片时如实保留概念属性，不伪造校准完成。

初稿用于搜索，校准稿随风格卡确认，无需增加两次独立确认。已有确认时只更新用户指定差异。

## 转成页面与素材约束

偏运营：落实到一个主要视觉概念、首屏焦点、参与动机及核心行动，不能仅增加渐变、字号和等规格卡片。

偏数据展示：落实到数字、单位、比较、时间、状态及图表密度，保持准确读数，不因视觉关键词删改业务字段。

需要图片且已获授权时，将执行词写成明确素材简报：用途、主体、风格材质、配色、构图、文字留白、裁切与避用元素。需编辑的标题、数据与按钮独立于位图；素材生成与同步遵从当前工具能力，不承诺不存在的能力。

验收时逐项对照已确认执行词及排除项，区分结构检查与真实画布视觉证据；关键词匹配不替代业务正确性检查。

## 示例（仅示范方法，不是默认风格）

页面：趣味测试结果活动页。
搜索词：趣味测试、结果海报、活动H5、分享页。
核心概念：我的选择身份卡。
执行词：立体纸张主视觉、结果先于说明、深蓝主色、蓝红点缀、金色行动按钮。
排除项：仪表盘堆排、过度光效、长篇说明、关键文字烘焙进背景。
以上属于初稿提案，必须结合本项目参考和用户偏好校准。
