# MasterGo UI Auto Sync

版本：v1.0.1

Mastergo自动同步第一版

将需求文字、需求图和现有页面转为 UI 设计，经参考研究与风格确认后同步到 MasterGo 可编辑画板。

## 工作流

需求分析 → 美叶、花瓣、站酷参考研究 → 风格确认 → 页面设计 → MasterGo同步 → 验收与迭代。

支持偏运营活动页与偏数据展示页面。偏运营强调主视觉、主题氛围、参与动机和分享；偏数据展示强调数字、单位、比较关系、时间和状态。

## 安装

将本仓库的 `mastergo-ui-auto-sync` 文件夹放入 `~/.codex/skills/`。运行环境需连接支持相关操作的 MasterGo MCP；参考浏览和原创图片需相应浏览器、生图能力。

## 使用

```text
使用 $mastergo-ui-auto-sync，根据附件原型设计页面。
页面倾向：偏运营
MasterGo目标：[链接]
页面宽度：393px
先分析需求，再依次查看美叶、花瓣、站酷并展示参考。
等我确认风格后同步，新增画板、保留旧版。
```

完整规则见 [SKILL.md](mastergo-ui-auto-sync/SKILL.md)。提交已受理不代表渲染或视觉验收完成，实际流程遵从当前MasterGo工具协议。
